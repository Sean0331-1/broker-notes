# 研報筆記站 Broker Research Notes

把我讀過的**券商個股研究報告**整理成一致格式的學習筆記，並自動彙整成「公司頁」，比較不同券商的評等與目標價。

- 🌐 網站：`https://<你的帳號>.github.io/<repo 名稱>/`
- 📘 專案規則（給 AI 看）：[`CLAUDE.md`](CLAUDE.md)

## 網站內容

| 頁面 | 說明 |
|---|---|
| 首頁 `index.html` | 個股筆記卡片，可依產業、公司、券商、評等篩選與搜尋 |
| 產業與技術 `industry.html` | 產業展望、技術介紹、市場規模分析等報告 |
| 公司頁 `company.html?code=6515` | 該公司所有報告的目標價走勢圖、觀點對照表與相關產業筆記 |
| 個股筆記 `reports/*.html` | 每份個股報告一頁，固定 8 個區塊 |
| 產業筆記 `industry/*.html` | 每份產業／技術報告一頁，固定 8 個區塊 |
| 名詞庫 `glossary.html` | 報告中的專有名詞，各頁共用 |

目前收錄 **83 份個股報告、24 份產業與技術報告**，涵蓋 16 家公司（測試、封測、CCL、載板、被動元件、散熱等 AI 供應鏈），來源包含 28 家本土券商、外資與研究機構。

## 怎麼新增一篇筆記

1. 把 PDF 放進 `raw-reports/`（此資料夾已被 `.gitignore` 排除，不會上傳）。
2. 對 AI 說：「依照 CLAUDE.md，把 `raw-reports/xxx.pdf` 整理成一篇筆記。」
3. AI 會依 `CLAUDE.md` §5 的 SOP：判斷是個股或產業報告 → 複製對應模板 → 填 8 個區塊 → 在 `data/reports.js` 或 `data/industry.js` 加一筆 → 補名詞 → 跑檢查清單。
4. 首頁、產業列表、公司頁、走勢圖、名詞都會自動更新。

## 技術

純 HTML / CSS / JavaScript，沒有框架、沒有 build。雙擊 `index.html` 即可在本機開啟，推上 GitHub 後用 GitHub Pages 發布。

## 聲明

本站為個人學習筆記，僅摘要整理報告重點，不構成投資建議。原始報告著作權屬各券商所有，本 repo 不包含任何原始報告。
