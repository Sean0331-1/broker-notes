AI 強勁動能延續，營運能見度延伸至未來三年

穎崴 6515｜凱基投顧｜動態更新

一句話結論

投資論點

  1. Agentic AI 帶動 CPU 訂單翻倍：受 Agentic AI 帶動，美系 server CPU 客戶今年已第二度上修訂單，總量較原先估計接近翻倍。
  2. 下一代 GPU 腳數增加：供應鏈調查顯示下一代 AI GPU 已進入工程開發，腳數比前代多 20–30%，提高測試座複雜度、ASP 與毛利率。
  3. 產能及時到位：緊急承租的仁武一廠四月如期投產；自建二廠原訂 2027 年底完工，凱基認為可望提前。
  4. 探針卡潛力被低估：除網通 IC、CPU、電競 GPU 外，憑藉與美系 GPU 龍頭的合作基礎，有望成為 AI GPU 探針卡主要供應商。
  5. 評價：2025–28 年獲利 CAGR 預估 79%，以 2028 年 EPS 的 50 倍本益比，目標價由 8,500 元調至 13,000 元。

成長動能

  • 1Q26營收季增 33.4%、年增 29.7%，探針卡與智慧型手機測試座季增最強；探針卡外購成本降低，毛利率季增 1.3 個百分點，EPS 19.6 元。
  • 2Q26AI 測試座出貨提升、探針卡出貨持續強勁，營收估季增高個位數。
  • 2026–28 年美系 GPU 與 server CPU 是核心，美系電動車廠與 ASIC 客戶也將貢獻；營收由 130 億元成長到 2028 年 310 億元。
